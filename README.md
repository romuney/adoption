# Proteus Adoption — пакет передачи (2026-09-22)

Снимок рабочей папки проекта для агента-преемника: рефакторинг и развитие
дашборда «Proteus Adoption» в корпоративном BI Proteus. Собран из живой папки
проекта с сохранением структуры (чтобы работали относительные пути стендов и
команды из CLAUDE.md).

## С чего начать

1. **`CONTEXT.md`** — весь контекст: статус, архитектура, вердикты, грабли.
2. **`CLAUDE.md`** — навигация и команды (положить рядом с агентом как
   инструкцию проекта).
3. **`memory/`** — полные тексты памяти исходного агента (19 файлов).
4. **`skills/proteus-echarts-builder/`** — скилл, обязательный для правки
   любых `.chart.js` (поставить в `~/.claude/skills/` преемника).

## Что здесь есть / чего нет

Включено: макет (эталон вёрстки), прод-виджеты с NOTES и моками, YAML-экспорт
боевого Proteus, генераторы SQL + jinja-стенды, vm-стенды проверок, папки
поставок, дизайн-система, конфиг helicopter-ноды, память, скиллы.

**Не включено** (пересоздаётся/докачивается при необходимости):
- `.venv/` — python3.9+jinja2 (`python3 -m venv .venv && .venv/bin/pip install jinja2`);
- `.render/node_modules/` — `npm install` внутри `.render/` (нужно только
  CDP-скриптам check.js/screenshot.js);
- `Макет/_shots/` (скриншоты состояний — переснимаются стендом);
- `.html_css/` (чанки фронтенда Proteus — докачиваются с
  `proteus.tcsbank.ru/static/prod/…`, знания из них отdistиллированы в
  `memory/proteus-adoption-html-embedding.md`);
- `Макет/_app_v3_backup.js` (бэкап старой версии макета).

## Требует корпоративной среды (вне этого репо не заработает)

Живой Proteus (чтение/правка) — MCP-скилл `proteus` или `.pmcp.sh` (нужен CLI
`dp`; в `.pmcp.sh` — внутренний URL шлюза: для внешнего репо удалить файл).
Исполнение SQL — SQL Lab владельца. Greenplum/Helicopter — владелец. Всё
остальное (макет, vm-стенды, генераторы, jinja-стенды) работает офлайн.
