В проекте Proteus Adoption пользователь явно попросил: все действия, находки и решения немедленно записывать в память проекта (файлы memory/), потому что макетирование будет делать другой агент, и между сессиями нельзя терять контекст.

**Why:** работа разбита на сессии и на разных агентов; память проекта — единственный передаточный механизм контекста.

**How to apply:** в конце каждого смыслового шага (прочитал конфиг, принял решение, изменил чарт/ноду) — обновлять [[proteus-adoption-project]] (журнал действий) и профильный файл памяти; новые находки — в [[proteus-adoption-audit-opportunities]] или [[proteus-adoption-datamodel]]. Не держать важное только в чате.
