Тестовые проходки, тестовый SQL, тестовые python-функции, дампы MCP и прочий
скратч в рабочей папке НЕ оставляем — удаляем сразу по закрытии этапа.

**Why:** папка «Proteus Adoption» разрослась до 500+ файлов скратча, владелец
перестал ориентироваться («открываю папку — миллион файлов, непонятно для чего»).
Ревизия 2026-09-19: удалено ~400 файлов из корня, применённые поставки — тоже.

**How to apply:** корень проекта = белый список живых инструментов (таблица в
CLAUDE.md) + действующие папки поставок; всё временное — в $TMPDIR или удалять
по завершении. Выжившие грабли/решения фиксировать ОДНОЙ финальной строкой-правилом
в CLAUDE.md или памяти проекта (см. [[always-log-to-project-memory]]), без
поитерационных файлов. Применённые и перекрытые поставки («Обновление …»)
удалять, держать только действующие.
