# Макет нового дашборда (2.5, 2026-09-21)

`Макет/index.html` офлайн (ECharts 5.5.1 в vendor/). Файлы: assets/{app.css,data.js,ui.js,charts.js,app.js},
`_test.js` (зелёный), `Архитектура 2.5.md` (source of truth: блок → чарт → датасет → эмит/приём).
История: 2.0 один экран → 2.1/2.2 две симметричные вкладки, у каждой свой каталог → 2.3 поимённый «Кто
смотрит» с деревом → 2.4 ось-календарь, пилюльки-пересчёт, чипы у контента, настройки списка → 2.5
двунаправленная связка каталог ⇄ «Кто смотрит» (устный фидбек владельца). v3-код в `_app_v3_backup.js`.

## Две вкладки: главные механики
- **«Отчёты»**: каталог слева задаёт область (клик переключает, Shift накапливает, повторный по
  единственной снимает); правая панель Динамика ⇄ «Кто смотрит», переключатель в обоих состояниях.
  Динамика: стек + пилюльки-пересчёт, ось-«календарь» (метка на каждой точке, второй ряд — смена
  месяца/года). Когорты полноширинно внизу.
- **«Кто смотрит»** = поимённый список: сигаретка частоты с процентами, тулбар [группировка|настройки]
  [счётчик N из M · выбрано: K][свернуть/развернуть], дерево групп (Департамент → блок→деп→люди),
  строка человека: ФИО+рук.+логин / подразделение+спец / стаж / дней / визит / сегмент.
- **«Аудитория»** — зеркало: свой каталог, 6 KPI (Adoption за год), панель ЦА+воронка, динамика охвата,
  «Кто из ЦА» в форме «Кто смотрит» (8 разрезов ⇄ поимённо+segstrip). Сводная: клик строки = audUnit.

## Две шины (главное решения 2.5 — людская без самовлияния)
- **Отчётная**: каталог → KPI/наблюдения/динамика/«Кто смотрит»/когорты своей вкладки; эмит
  mode_param+sel_f; каталог себя не перечитывает.
- **Людская**: пишет «Кто смотрит» — клик по СТРОКЕ группы И ЧЕЛОВЕКА (pickEmp, семантика как pick():
  переключает/Shift копит/повторный снимает; между разрезами И, внутри ИЛИ). Читают: каталоги ОБЕИХ
  вкладок + динамика ⟳. Панель-источник себя НЕ сужает (BI-паттерн: источник не фильтрует себя):
  выбранная строка подсвечивается (sel), группы без людей выборки ГАСНУТ (grp-dim), но остаются;
  контент-группы всплывают вверх. Контекст дерева = whoAreaPeopleNoBus (область без шины), содержимое
  списка = шина-калибровано (сходимость с KPI сохранена). Счётчик «выбрано: K» в тулбаре, чип человека
  подписан ФИО (FIO_BY).
- Свиток «только сертифицированные» УБРАЛЕН (2.5, требование владельца); ✓-бейдж в каталоге остался.
- В проде клику по человеку нужна ЛОГИН-колонка в людской маске куба (в v5.1/v6-прототипе её нет) —
  требование к кубу v6.

## Целостность чисел
Содержимое «Кто смотрит» (N из M, сигаретка) — по шина-калиброванной области = KPI users. Счётчики
дерева — контекстные (область без шины); расхождение подписано в тултипе («в области»/«в выборке»).
visitorsOf детерминирован; MAU = столбик последнего закрытого месяца; Adoption = visitorsOf('m',12мес).

## Датасеты мока (структура = будущие SQL)
ds_overview (ts/kpi/freq/cohort/mau, 4 грануляции × 8 разрезов), ds_reports (report+rts+rfreq+rmau
+групповые gkpi/gts/gfreq/gmau, дедуб 1/(1+.16·ln N)), ds_audience (population 4000/27400, AD_GROUP_DEF,
audienceRows/audienceDynamics). Логины мока УНИКАЛЬНЫ (2.5: раньше генерились из ФИО, 399 уникальных
на 4000 — тёзки делили логин, клик по человеку подсвечивал толпу; теперь п.иванова, п.иванова2…).

## Палитра

#5CC0EE; когорты дивергентные #FFD758←белый→#62CDFF→#5CC0EE. Скругление 2px, вес ≤700.

## Зоны/paint()
Разметка зонами data-sig + детерминированные id; сортировка/группировка не перерисовывают графики,
выбор области — перерисовывает. whoPanel/rightPanel ленивые внутри zone(); aside-зона «Аудитории» —
единственный сплит БЕЗ display:contents; колонке каталога minmax(533px,…).

## Грабли (накопленные)
- Prep-скрипты скриншонов: NodeList до клика → после синхронного ререндера это СИРОТЫ, MouseEvent по
  ним не доходит до document-делегата — переснимать querySelectorAll после каждого клика.
- Числа на сжатом скрине (2000px из 3840) нечитаемы — «прочитал» не то дважды; сверять только CDP-дампом.
- Двухэтажная шапка панели = «уезжающие» кнопки; строки групп держат text-align:left (база .ptable td
  right). Скрин captureBeyondViewport:true в headless отдаёт СТАРЫЙ кадр — высокая вкладка + false.
