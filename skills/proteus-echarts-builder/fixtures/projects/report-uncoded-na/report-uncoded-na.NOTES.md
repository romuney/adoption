# NOTES — рабочая память по report-uncoded-na

Фикстура «прозаический N/A» режима B: в SELF_CHECK строка B3 с N/A без кода
причины — включая формулировку «в среде виджета» и тег `<name>` внутри строки,
на которых СТАРАЯ проверка Z6b ложно срабатывала (подстрока «na» в `<name>`,
случай сессии «иерархический-фильтр»). Новая Z6b обязана отдать WARN
с подсказкой формата — и НЕ ронять сдачу.
