# pa-head — ШАПКА единого листа (период · «Считать» · дата данных + «Целевая аудитория»)

Точка восстановления: прочитать целиком, найти первый пункт плана ≠ DONE и продолжать с него.

## Задача (владелец, 2026-09-30)
«Зачем две плашки настроек? Один SQL, один JS, одна плашка наверху. Борд — три чарта: сверху настройки,
слева каталог, справа графики». Шапка pa-strip и строка ЦА pa-ca-bar — одним чартом.

## Устройство
- Датасет pa_head (`pa-head.data.sql`) = SQL pa_ca_dict (s / d / adg / total) + строка `section = 'md'`
  (k = последний день витрины из pa_pair). Фильтров не читает — ответ один, кэшируется. Прежний pa_strip
  не нужен: пилюли «Выбранные фильтры» рисует каталог, а эхо grain шапке не нужно (период — в state).
- JS (`pa-head.chart.js`) = pa-ca-bar (ns 'phead') + ряд шапки из pa-strip: период, переключатели,
  freshHtml. Корень — колонка из двух рядов; ряд ЦА отделён линией. Высота ячейки ~112 px.
- Одна маска: stripMask(state) + maskOf(state.applied) → applyCrossFilter. Сверке фильтров шапка шлёт ДВА
  ключа: PA_SEL src 'strip' (sheet '*', period/pub/act/exc) и src 'ca' (sheet 'aud', ca_*_f) — каталог и
  панель не менялись. PA_RESEND по любому из двух → вся маска + pa_nonce.
- Разворот iframe: signal('dd') — маркер UEEtQ0EtREQtT04x (640 px), signal('tip') — UEEtU1QtVElQLU9O
  (260 px), signal(false) — свернуть. baseH снимается при первом развороте из свёрнутого; высота строки
  закреплена (pin), пока окно не сжалось. Подсказка закрывается с задержкой 160 мс и только свою ('tip').
  CSS борда: оба блока — на id шапки.
