## Правка 2026-10-02, вечер — «Аудитория» каталога сходится с «Отчётами» и панелью (файлы 5, 6, 7)

- **Почему не сходилось.** В разрезы «Аудитории» входят только действующие сотрудники, а «Польз.» в «Отчётах»
  и «Пользователей» в панели — все зрители, включая увол. и служебные учётки. Теперь **ИТОГО = все зрители**
  (то же число, что слева в «Отчётах» и в панели), под ним — строка **«в т. ч. не сотрудники»**: на столько
  сумма групп меньше ИТОГО. «Охват» в ИТОГО — по сотрудникам (сотрудники-зрители / все сотрудники).
- **Почему было «Ничего не найдено».** Поиск каталога был общим для всех вкладок: название отчёта, найденного
  поиском в «Отчётах», фильтровало группы «Аудитории». Теперь у каждой вкладки свой поиск. Если выбранный отчёт
  смотрели только не сотрудники, вкладка показывает ИТОГО и «в т. ч. не сотрудники», а не пустоту.
- SQL 5 и 7 — по одной новой строке ответа («все зрители»), остальное без изменений; регресс check_one: ИТОГО
  «Аудитории» == ИТОГО каталога, «все зрители» выбранного отчёта == панель == «Польз.» отчёта в каталоге.
- Порядок: вставить SQL 5 (датасет каталога) и SQL 7 (датасет панели), затем JS 6 (каталог); Save, Cmd+Shift+R.
  Старый JS с новым SQL работает как раньше (новую строку просто не читает).
- Проверка: выбрать отчёт → «Аудитория»: ИТОГО «Польз.» == «Пользователей» в панели.

  ИТОГО «Сотр.» одно и то же — все сотрудники.
- Клик по группе → панель «Пересчитываем…», затем в заголовке «ЦА: <группа>». KPI «Пользователей» =
  «Польз.» этой группы в каталоге, «Охват ЦА» — её «Охват» (с точностью до округления). Повторный клик по
  группе — снять.
- Ряд «Целевая аудитория»: IT + Руководители → «Применить». Панель → «Кто смотрит» → «По целевой

  = число на полосе. Каталог при кликах по сегментам не меняется. Повторный клик — снять.
- «Кто смотрит» → «По частоте» → «1 день» — каталог сужается, как и раньше.
- У тех, кого нет среди действующих сотрудников, рядом с ФИО — серая пометка «увол.» (раньше было красное
  «уволен»).
- Скорость: панель и каталог не медленнее прежнего. Если заметно медленнее — пришли время из SQL Lab и
  время запроса `chart/data` из вкладки Network браузера.
