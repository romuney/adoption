## Правка «слева 73 %, справа 59 %» — файлы 1, 2, 4, 7

Каталог считал «Охват ЦА» как **всех** зрителей отчёта / ЦА, а панель — как зрителей **из ЦА** / ЦА
(«Дошли»). В числитель каталога попадали зрители без прав: права сняты или выданы иначе, уволенные.
Теперь каталог считает так же, как панель.

1. **GP:** добавь параграф «PA · доступ зрителей» — последний блок файла 1, после «PA · ЦА отчёта».
2. **Python:** добавь вызов для `pa_pair_acc` — последние строки файла 2. Запусти ноду.
3. **Датасет pa_body_aud** = файл 4 → Save → **синхронизировать колонки**: добавилась 20-я колонка
   `ca_users`.
4. **Чарт каталога вкладки** = файл 7. Тот же JS поставь и каталогу листа «Отчёты» (788805) — там
   ничего не поменяется.

Проверка: у выбранного отчёта «Охват ЦА» в каталоге = «охват ЦА» под «Дошли» в панели. В подсказке строки
каталога появилась строка «Из них заходили» — число зрителей из ЦА.

## Последние правки (2026-09-25, вечер) — замени из файлов 5, 6, 7, 8

- **Слово «штат» убрано.** База ЦА — действующие сотрудники с AD-логином (штатные и ГПХ), так и
  написано в интерфейсе.
- **AD-группы в строке считаются точно.** Датасет строки (файл 5) теперь отдаёт состав групп, и число
  «в ЦА» учитывает группы сразу, до «Применить». Числа у групп пересчитываются под остальные условия,
  группы без людей скрыты.
  - Объём ответа строки — проверка `Проверки/SQL Lab — строка ЦА, объём ответа.sql`: больше ~5 МБ —
    пришли ответ.
- **«Уволен»** — пометка у зрителей, которых уже нет среди действующих сотрудников с AD-логином.
  Стоит в «Кто из ЦА» (файл 6), в выгрузке CSV — колонка «Уволен».
- Файл 7 (каталог) — только текст подсказки «Охват ЦА»; тот же файл заменить и у каталога листа
  «Отчёты» (788805).

**Первый лист тоже:** пометка «уволен» в «Кто смотрит». Из папки `Обновление 2026-09-22 (v7…)` замени:
- датасет **pa_people** из файла 3;

pa_people теперь читает `prod_proteus.pa_staff` (его делает GP этого листа — таблица уже есть).
