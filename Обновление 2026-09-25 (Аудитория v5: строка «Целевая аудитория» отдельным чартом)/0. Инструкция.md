# Лист «Аудитория» v5: строка «Целевая аудитория» отдельным чартом (2026-09-25)

Настройка ЦА переезжает из плашки внутри панели в тонкую строку над листом. Строка — это кнопки:
Управленческая структура · Специализация · Стрим · HQ · IT · Руководители · AD-группы. Клик по кнопке
открывает выпадашку **поверх** каталога и панели: поиск, галочки и числа, которые учитывают
остальные условия. Справа в строке — «в ЦА N», «Сбросить» и «Применить».

Что это даёт:

- **Панель больше не слушает саму себя.** ЦА приходит в неё кросс-фильтром от строки, как в
  каталог. Поэтому условие «AD-группы» и имена ни разу не заходивших приходят с первым же ответом.
- Клики по людям и группам в «Кто из ЦА» снова не перезапрашивают панель.
- Числа выпадашек совпадают с ЦА панели и каталога на сервере (сверено регрессом).

Выпадашка поверх листа — тот же костыль, что у иерархического фильтра борда 59922 (заявка
платформе от 2026-09-14). Открыли выпадашку — чарт шлёт в канал скриншотов PNG с маркером, и CSS
борда разворачивает его iframe вниз. Закрыли — PNG без маркера, iframe снова размером с ячейку.

**Порядок с v4.** GP-часть v4 (шаги 1–2, «PA · штат» и диагностика) выполняется как написано.
JS панели из v4 (её файл 3) **не ставьте** — ставьте файл 3 отсюда.

| Файл | Куда |
|---|---|

## Шаг 1 — SQL Lab

Запустите **файл 1** в SQL Lab (CROSS). Ожидание:

- зелёное, меньше секунды;
- строки `s` (по подразделениям), `d` (словарь), `adg` (группы) и одна `total`, где `n` = штат —
  то же число, что `SELECT count() FROM prod_proteus.pa_staff`.

Красное → стоп, текст ошибки целиком мне.

## Шаг 2 — датасет и чарт строки

1. Создать датасет **pa_ca_dict** = файл 1 → Save. Колонки: `section, g, k, parent, n`.
   Синхронизировать колонки.
2. Создать чарт того же типа, что наши (react_sanbbox), на **pa_ca_dict**. Название —
   **«Аудитория: настройка ЦА»**, JS = **файл 2**, лимит строк **50 000**, без группировок.
3. На листе «Аудитория» поставить чарт **над** каталогом и панелью, **во всю ширину**. Высота — одна
   строка сетки, чтобы вышло ~64 px: строка рассчитана на одну линию.
4. Запомните **id чарта** — число из адреса чарта (`…/explore/?slice_id=NNNNNN`).

## Шаг 3 — CSS борда

1. Edit dashboard → CSS. **Файл 4** — в конец, ничего не удаляя. В нём замените все `000000`
   на id чарта строки (Ctrl+H). Правила — те же, что на борде 59922 у чарта 783469, только id и маркер
   свои. Красные «!» редактора у строк с `:has(...)` — линтер, не ошибка.
2. Save. Проверка: клик по кнопке «Подразделения» — список раскрывается **поверх** каталога и
   панели, а не обрезается по краю строки.
   - Обрезается → id в CSS не тот, либо CSS не сохранился. Стоп: скрин + id чарта + CSS целиком.

## Шаг 4 — панель и кросс-фильтры

1. Чарт **«Аудитория: ЦА области»** → JS = **файл 3** → Save. Датасет не меняется.
2. Кросс-фильтры (МЕНЯЮТСЯ):

| Источник | Получатели эмита | Самовлияние |
|---|---|---|
| «Аудитория: настройка ЦА» (новый) | каталог вкладки «Аудитория» + «Аудитория: ЦА области» | ВЫКЛ |
| «Аудитория: ЦА области» | **только** каталог вкладки «Аудитория» | **ВЫКЛ** (было ВКЛ в v3) |

   Строку исключите из получателей всех остальных чартов: её датасет фильтров не читает, лишний
   перезапрос ни к чему. Остальные строки таблицы кросс-фильтров — без изменений.

## Шаг 5 — приёмка

1. Лист «Аудитория». Слева в строке «Целевая аудитория · по правам доступа» и пояснение; кнопки-пилюли —
   только названия условий (Управленческая структура, Специализация, …), справа «штат N».
2. **HQ** → выпадашка поверх листа → отметьте значение.
   - Кнопка подсветилась, слева «изменения не применены».
   - Внизу выпадашки «В ЦА N человек».
3. **Подразделения**: числа у блоков пересчитаны под HQ, нулевые — серые внизу. ▸ раскрывает уровень,
   поиск ищет по всем уровням.
4. Клик мимо выпадашки, в том числе по каталогу, закрывает её. Esc — тоже.
   **После закрытия каталог и панель кликаются как обычно** — проверьте клик по отчёту.
5. **Применить**. Перезапрашиваются каталог и панель, строка — нет.
   - В каталоге «Охват ЦА» от новой ЦА.
   - В панели жёлтая рамка «Собрана по условиям: HQ: …».
   - «Целевая аудитория» в панели = «в ЦА N» строки. Возможна разница в единицы: панель не считает
     владельцев отчётов области, у которых свои визиты.
6. **AD-группы** → выберите группу → **Применить**.
   - Панель сразу считает ЦА с группой, без отдельной пометки «ждём сервер».
   - В «Кто из ЦА» → «ЦА не заходили» — имена (если их ≤ 20 000).
7. Клик по человеку в «Кто из ЦА» → перезапрашивается **только каталог**, панель не мигает.
8. **Сбросить** в строке → каталог и панель вернулись к ЦА «как роздан доступ».

Любое красное или подозрительное — стоп и мне скрин целиком.

## Известные ограничения

- Выпадашка поверх листа — костыль до нативного resize-канала платформы (заявка 2026-09-14). Если
  платформа поменяет классы `img.echarts-plugin` или `dashboard-chart-id-*`, выпадашка снова начнёт
  обрезаться ячейкой. Остальное продолжит работать.
- Пока выпадашка открыта, область под ней (до ~640 px вниз) принадлежит строке: первый клик туда
  закрывает выпадашку, а не нажимает на каталог.
- Числа выпадашек — весь действующий штат, без учёта области и прав. «С доступом к области» —
  ступень воронки в панели.
- После F5 применённая ЦА сбрасывается к ЦА по правам (кросс-фильтр борда).
