# CROSS DATA — согласованный акцентный знак

`cross-data-accent-source.png` — результат генератора изображений из варианта «02 / Акцентный», согласованного владельцем в этом чате. Исходный загруженный владельцем `../../CrossData_new.png` сохранён отдельно и не изменён.

`cross-data-accent.webp` — та же графика для встраивания в JS: 480×160, WebP без потерь после подготовки размера. В интерфейсе ширина 120 px в шапке и 110 px в загрузке; запас в четыре раза для экранов высокой плотности. Полупрозрачность задаёт CSS: 0.60 в шапке, 0.65 в загрузке. Весь чарт автономен: внешнего запроса к изображению нет.

Повторить подготовку ресурса (FFmpeg с libwebp; сборка JS использует уже готовый файл):

```bash
ffmpeg -i 'cross-data-accent-source.png' -vf scale=480:160:flags=lanczos \
  -c:v libwebp -lossless 1 -compression_level 6 'cross-data-accent.webp'
```

Оба хэша включены в `../ui-build.json`. Изображение не содержит метрик или программного кода.
