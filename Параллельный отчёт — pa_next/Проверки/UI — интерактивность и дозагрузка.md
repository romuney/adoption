# UI: интерактивность и дозагрузка

Проверено 2026-11-14 на Chromium 156 в sandbox iframe с CSP connect-src none. Использованы актуальные Web Interface Guidelines, полученные по HTTPS, и профиль Proteus/Superset 2.1.0. Живой корпоративный Proteus не подключён. Изменяются только экспериментальный основной JS, CSS и JSON; SQL, YAML и формулы расчёта не менялись.

## Результат

- Высота главного чарта следует окну. Заголовки борда/чартов, служебные меню и native filters скрыты в просмотре; редактор возвращает их. Helpers 859563/859564 продолжают исполняться в положительном размере 2×2 px.
- «Как работать» — интерактивный гид из 13 доступных шагов с подсветкой, клавиатурой и возвратом фокуса. Отсутствующие элементы пропускаются.
- Каталог растягивается разделителем, клавишами и кнопками −/+, скрывается и возвращается с прежним состоянием. SVG пересчитываются сразу, без кратковременного увеличения подписей при скрытии.
- Шапка имеет явный нижний отступ 12 px. На узком экране её элементы переносятся; кнопка гида доступна.
- Готовый preview не закрывается общей плашкой. Не полученные числовые блоки показывают индикатор и скелетон; вкладки доступны. Анимация отключается при prefers-reduced-motion.

## Проверка чисел при дозагрузке

Данные теста — реальные ответы локального ClickHouse 24.8.4.1 на синтетическом мире; бизнес-строки не переписываются. В браузере подменяется только служебный nonce текущего окна. Исходные полные SQL-ответы и их SHA проверяются отдельно.

Воспроизведение:

```bash
PA_DB=/workspace/.cache/pa-next-db /workspace/.venvs/pa-next-test/bin/python tools/parallel/export_browser_fixtures.py --output /tmp/pa-next-periods
PA_DB=/workspace/.cache/pa-next-db /workspace/.venvs/pa-next-test/bin/python tools/parallel/export_browser_preview_fixtures.py --periods /tmp/pa-next-periods --output /tmp/pa-next-preview
/workspace/.venvs/pa-next-test/bin/python tools/parallel/test_ui_preview.py --periods /tmp/pa-next-periods --fixtures /tmp/pa-next-preview
```

Экспорты не запускать одновременно с другим процессом, открывшим этот chdb-каталог. Числовые фикстуры не являются данными прода.

Preview разрешается только после проверки исходного каталога, поколения обеих частей, точного nonce каталога, текущего выбора и дословного pv/pvh. Подпись берётся из доверенного локального сообщения каталога. Для недоступного preview (группы, множественный выбор, пользовательский период, фильтры людей, вне top500) панель ждёт полный SQL-ответ. Уникальные пользователи нескольких отчётов не складываются.

Независимый ревьюер воспроизвёл и проверил исправление возврата FULL A→preview B→A до отправки фильтра: раньше DOM сохранял 170 пользователей отчёта B при выборе A; теперь восстановлен полный ответ A с 235 пользователями. Это проверка синтетического среза, не значения боевого отчёта. Совместный выбор двух отчётов дал 397 уникальных пользователей из SQL, а не сумму 235 + 170 = 405. Финальные машинные результаты и SHA: [UI — preview.json](UI%20—%20preview.json).

## Ограничение проверки

DOM-модель соответствует известным селекторам Superset 2.1.0; текущий Proteus fork и фактическая высота его навигации здесь не проверены. CSS использует боевой резерв меню 48 px; без #main-menu резерв снимается. При нестандартной навигации настройка --pa-next-nav-height указана в CSS. Проверить установку на отдельном борде: обновить JS4, CSS9 и JSON10, затем открыть отчёт и гид, выбрать подготовленный отчёт, переключить вкладки, скрыть каталог и изменить окно. Ноду для этого обновления запускать не требуется.
