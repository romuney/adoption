# Стабильная загрузка, шрифт и прокрутка

Проверено 14.11.2026. Для применения заменить **файл 4 целиком в чарте 859562**, сохранить и обновить страницу борда. CSS 9 остаётся из исправления `d148f42`; ноду запускать не нужно. Загрузчики, JSON, SQL, YAML и исходные виджеты не изменены.

SHA-256 проверенного файла 4: `edcede4c123d6e0290e4414c7086dba06f891d7c4f7f7763515e221e43e90ea0`.

## Причины и исправления

- При повторном выполнении основного JS управление высотой и раскладкой уничтожалось и создавалось заново. Промежуточное схлопывание области сбрасывало `scrollTop` со 121 до 0 px; правая панель визуально опускалась. Теперь экземпляры сохраняются, пока используется та же оболочка iframe. Сохранены прокрутка, вкладка, фильтры и кэш; обработчики не дублируются.
- При движении разделителя SVG некоторое время сохранял старый `viewBox`, и браузер масштабировал вместе с ним текст. Теперь локальная подгонка размеров выполняется до следующего кадра. Обычная прокрутка не пересобирает DOM и не запускает подгонку при неизменных размерах.
- Абсолютный индикатор загрузки исключён из подсчёта промежутков flex. Старые числа остаются скрыты во время пересборки ожидающей панели.
- Минимум каталога — 420 px. Даже выбранное длинное название ограничено тремя строками; полный текст доступен в подсказке. При необходимости каталог скрывается кареткой, размер шрифта аналитики не уменьшается.
- Для скролла заданы общие цвета и тонкие полосы. У краёв основных областей оставлены 10 px, включая случаи, когда полоса не занимает ширину в раскладке. Нижний отступ учтён в доступной высоте, чтобы не создавать лишнюю прокрутку на большом экране.

## Границы проверки

Тесты выполнены в Chromium на локальной модели борда с изолированным iframe; это не прогон в живом Proteus. Нулевая ширина gutter моделирует геометрию overlay-полос, но не нативное отображение macOS. Safari и Firefox отдельно не запускались. Автоскрытие и отдельные детали полос остаются под управлением браузера/ОС; пиксельное совпадение всех систем не обещается. Эквиваленты zoom проверены размерами CSS viewport, не нативным масштабированием браузера.

Команды воспроизведения — в [TESTING.md](../../tools/parallel/TESTING.md). Новый код не публиковался в Proteus; применение выполняет владелец.
