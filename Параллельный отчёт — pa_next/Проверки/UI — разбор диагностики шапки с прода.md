# Шапка: первая диагностика с прода

Источник — [pa-next-header-diagnostic.json](../pa-next-header-diagnostic.json), добавленный владельцем в коммите `104f73f`. Это наблюдения из реального браузера, а не подтверждение воспроизведения всей платформы на локальном стенде.

## Что подтверждено

Контекст `top`, Chrome 156 на macOS. `:has`, `:focus-within` и `clip-path` поддерживаются; ошибок коллектора нет. Обе старые Markdown-ссылки существуют, ведут в тот же документ, не имеют `target=_blank`. Адресат `#chart-id-859562` присутствует. Шапка имеет ожидаемый класс `.dashboard-header-container`.

| Проверка | Результат |
|---|---|
| Совпадение составного селектора установленного контрола | 1 элемент |
| Совпадение селектора разрешённого скрытия | 1 элемент |
| Совпадение селектора открытого состояния после Open | 1 элемент |
| Отмена click другим обработчиком | Нет |
| Смена fragment после Close / Open | Работает |
| Вычисленный `position` шапки | `static`, а ожидался `fixed` |
| Вычисленные `transform` / `clip-path` шапки | `none` / `none`, включая закрытое состояние |
| Markdown-ссылки | `position:static`, кегль 14 px |
| Markdown-компонент и его ряд | Высота 400 px, вместо ожидаемого нуля |

Следовательно, причина не в недоступном адресате или несовпадении составных селекторов v2 с реальными элементами. Поведение кликов есть, а ожидаемого эффекта CSS нет. При Open меняется fragment и прокручивается контейнер борда; это не скрытие шапки правилами переключателя.

## Чего выгрузка не доказывает

Первый коллектор ограничивал чтение первыми 150 stylesheet. В выгрузке ровно 150; ни одного CSS-правила с `.dashboard-header-container` в прочитанной части нет. Это **не доказывает отсутствие** правил в документе: поздние стили могли остаться за пределом, а общее число таблиц скрипт не записывал. Нельзя пока отличить незагруженный/неприменённый блок CSS, обработку редактором платформы, ограничение области действия CSS и перебивающие правила. Нельзя утверждать, что владелец вставил не тот файл.

Коллектор обновлён до `pa-next-header-diag-2`: инвентаризирует все таблицы стилей, сохраняет общее и обработанное количество, показывает достижение лимитов правил. Локальный регресс располагает рабочие правила в таблице №177 и подтверждает, что они попадают в результат. CSS9, JS4, Markdown14 и поставка данных этим изменением не меняются.

Повторная выгрузка получена: [pa-next-header-diagnostic (1).json](<../pa-next-header-diagnostic (1).json>). Все 338 stylesheet прочитаны; блок v2 присутствует в `style.CssTemplate-css` под индексом 336 и вложен в `CSSScopeRule`. Причина и исправление описаны в [разборе CSS scope](<UI — шапка внутри CSS scope.md>); повторять сбор для установки исправления не нужно.
