# Раскрытие штатной шапки без перекрытия отчёта

Предыдущее исправление `@scope` включило переключение на проде, но раскрытая шапка оставалась fixed и накрывала внутренний заголовок Proteus Adoption. По уточнению владельца это поведение изменено: открытая шапка должна занимать своё место в потоке, а закрытие должно быть очевидным.

## Поведение v4

В открытом состоянии native header возвращается в поток (`position:relative`), а переменная расчёта высоты iframe получает 65 px. Отчёт опускается на 65 px и уменьшается по высоте на столько же; его нижний край и ширина сохраняются. Внутреннее название не накрывается штатной шапкой. Переход намеренно без анимации промежуточных размеров.

Справа в раскрытой шапке видна ссылка **«Свернуть ↑»**, размер зоны 112×32 px. Для неё зарезервирована ширина рядом со штатными действиями; Edit и меню сохраняют доступ. Это псевдоэлемент существующей Markdown-ссылки закрытия, поэтому переустановка Markdown не требуется. Есть hover и отдельная видимая рамка клавиатурного фокуса. По умолчанию шапка и действие скрыты; новых постоянно видимых кнопок нет. Повторный клик по прежней восьмипиксельной верхней полосе также закрывает шапку.

CSS остаётся совместимым с `@scope` и обычным stylesheet, старыми ссылками на график и новой ссылкой `#app`. Отсутствующий/неисправный контрол оставляет штатную шапку доступной, режим редактирования сохраняет нативный вид. JS4, Markdown14, SQL и YAML не изменены.

## Проверки

Браузерный регресс `tools/parallel/test_ui_header_scope.py` использует полный отчёт и дерево Markdown из диагностики прода. Отрицательный контроль v3 из коммита `f77879c` подтверждает перекрытие внутреннего названия при открытии. Два прежних отрицательных контроля v2 сохраняют проверку ошибки CSS scope.

Для актуального CSS проверяются 12 сочетаний: обычный stylesheet и две области `@scope` × старые/новые ссылки × 1366×768 / 1920×1080. Помимо переключения, проверяется заданный сдвиг iframe, уменьшение его высоты, неизменность нижнего края и ширины, видимость и неизменный кегль внутреннего заголовка, отсутствие пересечения действия закрытия с Edit и реальный клик по видимому псевдоэлементу. Затем проверяются повторное открытие, закрытие через прежнюю полосу, меню и клавиатурный доступ к редактированию. Принятые данные и число filter emissions остаются неизменными.

Прежний регресс `test_ui_header_focus.py` проверяет пять вариантов обёрток, абзацев и позднего адресата; его ожидания геометрии обновлены под новое требование. Сборщик проверяется `build_ui.py --check`, диагностический скрипт — `test_header_diagnostics.py`.

Пройдены 12/12 сочетаний и 5/5 прежних сценариев, все отрицательные контроли, проверки сборщика UI, ESLint, диагностического коллектора и статической изоляции поставки. ## Установка

На текущем борде заменить **только файл 9 целиком в общем CSS дашборда**. Markdown оставить, JS и ноду не менять. Фрагмент адреса `#app` или `#chart-id-859562` сохраняет раскрытое состояние после перезагрузки; «Свернуть» закрывает шапку, а для начального закрытого состояния можно удалить fragment начиная с `#`.
