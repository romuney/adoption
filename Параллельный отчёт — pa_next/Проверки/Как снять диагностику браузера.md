# Снять смещение и обрезание отчёта в живом Proteus

Нужен **новый борд с основным чартом 859562** в обычном просмотре, где видна ошибка. Не SQL Lab, не редактор JS чарта и не старый боевой отчёт.

## Запустить запись в двух контекстах

1. Открой борд, дождись исходного готового состояния. Открой DevTools (**F12** или **Ctrl+Shift+J**; на Mac **⌥⌘J**) → вкладка **Console**.
2. В списке контекста над строкой ввода оставь **top**. Вставь **целиком** [файл 13](<../13. Консоль — диагностика интерфейса.js>) и нажми Enter. Ожидается `контекст=board`.
3. В том же списке вместо `top` выбери iframe основного чарта. Это `react_sanbbox` / sandbox внутри элемента `chart-id-859562`; название зависит от форка. Проверка выбранного контекста:

   ```js
   Boolean(window.__paNext)
   ```

   В правильном iframe результат **true**. Если false — выбран другой контекст. В правильном iframe вставь **тот же файл 13 целиком**. Ожидается `контекст=report`.

4. **Закрой DevTools**, чтобы он не уменьшал рабочее окно. В течение ближайших 90 секунд воспроизведи: докрути отчёт вниз → кликни отчёт/сними фильтр → дождись загрузки или зафиксируй зависание. Вкладку браузера не обновляй: это сотрёт запись.
5. Открой DevTools снова. В контексте **top** выполни:

   ```js
   copy(__paNextDebug.finish())
   ```

   JSON попадёт в буфер обмена. Сохрани его в Git как **`debug-board.json`**.
6. Выбери тот же iframe, где `Boolean(window.__paNext)` даёт true, и повтори ту же команду. Этот JSON сохрани как **`debug-report.json`**.

Положи оба файла, например, в `Диагностика/` в ветке `new`. Допиши одной строкой последовательность кликов и какой элемент остаётся обрезанным. Если iframe пересоздался и `__paNextDebug` исчез — сохрани хотя бы board-файл и укажи это; не требуется добиваться идеального повторения.

Если выполнить второй запуск сложно, присылай `debug-board.json`: он уже содержит высоты борда и iframe, реальную прокрутку, структуру родителей и ограничения доступа. Второй файл нужен для точного состояния внутреннего интерфейса и очереди — обычная страница не может читать изолированный iframe.

## Что попадёт в файлы

- Размеры окна, visual viewport, DPR/масштаб, навигации, шапки, ячейки и iframe.
- Размеры и ограничения прокрутки каждого слоя, grid/flex, min-height, padding, overflow, transforms, CSS zoom и относящиеся к раскладке CSS-правила.
- Геометрия правой панели, KPI, вкладок, загрузки и обеих SVG до, во время и после клика; короткие серии кадров и история прокрутки.
- Внутри iframe: текущая/отправленная маска, ожидающие команды, реальные flight, поколения, serial/instance, cache/preview — без раскрытия значений фильтров.
- Служебные сообщения между чартами, количество строк по секциям (без самих строк), времена завершённых запросов без URL/тел запросов/ответов.

Скрипт **не читает cookies, localStorage/sessionStorage, текст таблиц, поля ввода, SQL или значения метрик**. Значения фильтров заменяются непрозрачными метками, чтобы можно было сопоставить выбор и ответ. Он не отправляет запросов, не вызывает applyCrossFilter и не меняет стили/выбор. Наблюдатели снимаются при `finish()` либо через 90 секунд.
