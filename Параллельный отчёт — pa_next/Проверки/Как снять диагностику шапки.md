# Диагностика шапки на проде

Обновление после первой выгрузки: используй текущую версию файла 15 (`pa-next-header-diag-2`). Она проверяет **все** таблицы стилей, включая добавленные платформой после первых 150. Для дополнения уже снятой диагностики достаточно заново вставить файл и сразу выполнить `__paHeaderDiag.save()`; повторять клики не требуется. Добавь новый JSON вместо предыдущего.

1. Открой проблемный дашборд в обычном режиме просмотра, дождись загрузки.
2. Открой инструменты разработчика браузера → **Console**. В списке контекстов над консолью выбери **top**, а не iframe чарта.
3. Скопируй **всё содержимое** файла [15. Консоль — диагностика шапки.js](<../15. Консоль — диагностика шапки.js>), вставь в консоль и нажми Enter. Не вставляй в редактор JS чарта или общий CSS.
4. Должно появиться «Запись шапки включена». Если написано «Выбран iframe», переключи контекст на **top** и запусти скрипт заново.
5. Не обновляя страницу, воспроизведи проблему: нажми «Открыть шапку дашборда», затем «Закрыть шапку дашборда». Если ссылки уже скрыты, кликни 2–3 раза по верхнему краю содержимого дашборда, сразу под глобальной навигацией Proteus. Между кликами подожди около двух секунд. Если ничего не происходит, это тоже нужный результат — не исправляй стили вручную.
6. В консоли выполни:

   ```js
   __paHeaderDiag.save()
   ```

7. Браузер скачает **pa-next-header-diagnostic.json**. Добавь его в репозиторий, например в `Параллельный отчёт — pa_next/Проверки/`, и сообщи, что файл добавлен.

Если скачивание не сработало, выполни `copy(__paHeaderDiag.finish())`, вставь содержимое буфера в текстовый файл и добавь его в репозиторий. `copy` — команда именно DevTools Console. После сохранения запись остановится; повторная вставка всего скрипта начинает новую запись. Обновление страницы удаляет запись из памяти, поэтому сохраняй до обновления.

Скрипт собирает структуру элементов без текста отчёта, размеры, вычисленные стили, CSS-правила шапки и результат проверки селекторов, адресаты ссылок, перекрывающие элементы в верхней области, историю кликов, фокуса и изменения URL-фрагмента. Значения полей, содержимое таблиц, cookies, storage и параметры URL не выгружаются. Скрипт не применяет CSS, не меняет фильтры и не делает сетевых запросов. Для скачивания создаётся временный Blob URL. Через десять минут слушатели автоматически отключаются.

Локальная проверка коллектора: `python3 tools/parallel/test_header_diagnostics.py`. Она проверяет сбор DOM/CSS, реальные клики открытия/закрытия, скачивание JSON, отсутствие изменений раскладки и утечек тестовых значений, повторный запуск и предупреждение о неверном контексте. Это проверка диагностического скрипта, а не подтверждение исправления живого Proteus.
